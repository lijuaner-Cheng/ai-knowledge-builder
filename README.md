# 个人知识库搭建 Skill

用一句话让 AI 搭一套独立、Obsidian 可读的个人知识库。对话里说"记下来"才保存；之后可以检索、关联、编辑、可逆归档和版本回退。

## 一句话启动

把本 Skill 发布到你自己的 Git 仓库，任何人把下面这句话发给有本地文件读写、命令执行和 Python 3.9+ 能力的 Agent，即可完成初始搭建：

> 请按这个 Skill 帮我搭建自己的 AI 知识库：[https://github.com/lijuaner-Cheng/ai-knowledge-builder]

把链接换成仓库实际地址。Agent 会读取完整仓库、检查依赖、选择被授权的持久化目录、保护已知的旧库，然后创建**一套空的正式库**。不需要你提供 UUID、参数、模式或验收计划。没有可用持久目录时，宿主会请求目录权限。

## 日常使用

- "记下来：……" —— 只保存你明确要求的内容。
- "找找我之前关于……的想法" —— 在自己的知识里检索。
- "改一下这篇"、"归档这个"、"恢复这个" —— 只做指定动作。
- "继续用这个知识库" —— 在同一对话续用已核验的实例。
- "再新建一套" —— 另建一套隔离实例。

换 Agent 或新对话时，把生成的 `handoff.json` 发过去，请对方继续。对方从中读取 root 和完整 key。若同时存在多个候选，Agent 会问你选哪个，不会按名字或时间猜。

## 六个架子

| 目录 | 归属 | 功能定位 |
|---|---|---|
| 00-灵感库 | 外部 | 待处理的零散想法、临时灵感 |
| 01-Projects（项目库） | 我的 | 当前正在推进的具体项目 |
| 02-Areas（资产库） | 我的 | 已处理完成的个人核心知识资产 |
| 03-Resources（资源库） | 外部 | 外部参考资料、未加工的素材 |
| 04-Archive（归档库） | 不改变归属 | 已完成、暂时不用但需保留的内容 |
| 05-Skills（技能库） | 我的 | 个人知识转化的固定模板与技能 |

## 关键行为

- 普通讨论只读。保存、修改、归档、恢复都需要当次明确授权；引用和示例里的"记下来"不算。
- 01-Projects / 02-Areas / 05-Skills 是"我的"；00-灵感库 / 03-Resources 是外部输入；04-Archive 不改变归属。找"我的"默认只在 owned 范围检索，不静默外扩。
- 笔记支持新增、列举/检索/阅读、编辑、可逆归档恢复、版本回退。
- 今日 / 日报 / 待处理事项导航只链接已保存的个人内容，位于 `01-Projects（项目库）/每日流/`。待定决策与已采纳行动分开存。
- 每套实例有自己的目录、完整 key、引擎副本、正文、历史、锁和提醒状态。
- 每次操作都要带 root + 完整 key；错 key、错引擎、路径不符、符号链接逃逸都会被拒。
- 搭建不导入旧笔记、不改全局路由、不注册真实定时任务，也不写样例笔记。

## 环境要求

- Python 3.9+
- 不需要 PyYAML 或 tzdata：frontmatter 与时区处理都内置

把整个仓库放到被允许的目录。Codex 可按其安装规则把完整目录装到 `~/.codex/skills/personal-knowledge-builder`；其他 Agent 直接读 SKILL.md 即可。只复制入口文件会丢运行时和参考文档。

## 验证与边界

自测覆盖创建、显式保存门槛、归属边界、编辑/归档/恢复/回退、身份校验、导航刷新，共 44 项断言。运行：

```text
python -B tests/test_core.py
```

这些检查只是减少工具失误，不是操作系统沙箱。更强的隔离需要宿主文件系统限制。文件搭建成功不代表 Obsidian 已完成 UI 注册、云同步、旧数据迁移或提醒送达。

## 目录结构

```text
SKILL.md                     Agent 入口与流程
README.md                    本文件
references/operating-rules.md 归属与保存规则
references/api.md             操作接口
mindvault.py                  安装器入口
vaultkit/                     运行时源码（seal/codec/ledger/compass/entry/manager）
tests/test_core.py            自测
```

实例创建后会把 `vaultkit/` 复制到实例内的 `engine/`，并生成 `handoff.json`。实例里的引擎与路径绑定，不能用 Skill 包里的源码副本操作它。
